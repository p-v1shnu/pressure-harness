# สิ่งที่เทสต์อัตโนมัติแทนไม่ได้

เอกสารนี้มีไว้เพื่อความซื่อสัตย์: CI รันบน Linux/macOS/Windows แต่ **บาง
พฤติกรรมพิสูจน์ได้เฉพาะบนเครื่องจริงที่มีหน้าจอ** รายการนี้คือสิ่งที่
"ผ่าน CI" ไม่ได้แปลว่า "ใช้ได้จริง" — ต้องมีคนกดดูเอง

เช็คตามตารางแล้วเติมผลลงในช่อง เพื่อให้รู้ว่าอะไรถูกยืนยันแล้วบ้าง

---

## 1. หน้าต่างขออนุมัติ (M4) — สำคัญที่สุด

หน้าต่างเป็น Tk ซึ่งเปิดไม่ได้ในคอนเทนเนอร์ที่ไม่มี display
ทุกข้อในตารางนี้จึงยังเป็น **"เขียนแล้ว ยังไม่ยืนยัน"**

วิธีลอง (บน Windows):

```
ph workspace add D:\work\my-project --alias demo
python -c "from pharness.adapters import select_notifier; print(select_notifier().name)"
```
ต้องได้ `tk` ถ้าได้ `console` หรือ `null` แปลว่า Tk ใช้ไม่ได้บนเครื่องนั้น

| # | สิ่งที่ต้องยืนยัน | ผล |
|---|---|---|
| A1 | หน้าต่างเด้งขึ้นมาจริง และ **อยู่หน้าสุด** แม้กำลังใช้โปรแกรมอื่นอยู่ | |
| A2 | ในหน้าต่างแสดง **คำสั่งดิบเต็มๆ** ไม่ใช่คำอธิบาย | |
| A3 | เลขนับถอยหลังเดินจริง และ **หมดเวลาแล้วปฏิเสธเอง** | |
| A4 | กดปุ่ม X ปิดหน้าต่าง = ปฏิเสธ (ไม่ใช่ค้าง) | |
| A5 | "จำคำสั่งนี้ไว้" แล้วสั่งซ้ำ → ไม่ถามอีก | |
| A6 | สั่งคำสั่ง**อื่น** → ถามใหม่ (การอนุมัติต้องไม่ลามไปคำสั่งอื่น) | |
| A7 | ปิดคอนโซลทิ้งไว้ แล้วสั่งงาน → หน้าต่างยังเด้งได้ | |
| A8 | ยิงคำสั่งรัวๆ เกิน rate limit → ถูกปฏิเสธ ไม่ใช่เด้ง 20 หน้าต่าง | |

## 2. Process บน Windows (M3)

เทสต์ `test_stopping_kills_the_whole_tree` รันบน Windows CI แล้ว
แต่ **dev server จริงซับซ้อนกว่า process ทดสอบ**

| # | สิ่งที่ต้องยืนยัน | ผล |
|---|---|---|
| P1 | `npm run dev` (Next/Vite) แล้วสั่งหยุด → **พอร์ตถูกปล่อยจริง** ตรวจด้วย `netstat -ano \| findstr :3000` | |
| P2 | ไม่มีหน้าต่าง console ดำๆ กระพริบขึ้นมาตอนรันคำสั่ง | |
| P3 | ปิดโปรแกรมทั้งหมดแล้ว ไม่มี process ค้าง | |

## 3. Path jail บน Windows (M1)

| # | สิ่งที่ต้องยืนยัน | ผล |
|---|---|---|
| J1 | สร้าง junction ชี้ออกนอก workspace (`mklink /J link C:\Windows`) แล้วลองอ่านผ่าน tool → ต้องถูกปฏิเสธ | |
| J2 | ลองอ่าน `NUL`, `CON`, `COM1` → ต้องถูกปฏิเสธ | |
| J3 | ลองเพิ่ม workspace เป็น `C:\` → ต้องเตือนและไม่ยอมถ้าไม่ใส่ `--yes` | |

## 4. Toolchain จริง (M3)

| # | สิ่งที่ต้องยืนยัน | ผล |
|---|---|---|
| T1 | `npm test` ทำงานได้ (env allowlist ครบพอ — ถ้าขาด `SystemRoot` จะพังแบบงงๆ) | |
| T2 | โปรเจกต์ที่ใช้ nvm / pnpm / corepack ยังรันได้ | |
| T3 | โปรเจกต์ Python ที่มี venv ยังรัน pytest ได้ | |
